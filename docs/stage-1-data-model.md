# 阶段 1：棋盘与方块数据结构定义

## 文档目标

这份文档只定义第一阶段最小可玩版所需的数据结构基础。

- 先把棋盘怎么存说清楚
- 先把方块怎么表示说清楚
- 先把坐标约定固定下来

本阶段不实现移动、旋转、自动下落、消行和计分逻辑。

## 数据脚本清单

- `res://scripts/game/data/board_state.gd`
- `res://scripts/game/data/piece_state.gd`
- `res://scripts/game/data/tetromino_data.gd`

## 棋盘数据表示

棋盘使用 `BoardState` 表示。

核心字段：

- `columns`：列数，第一阶段固定为 `10`
- `rows`：行数，第一阶段固定为 `20`
- `cells`：二维数组，访问方式为 `cells[row][column]`

单元格存储规则：

- 空格子使用空 `StringName`，即 `&""`
- 被占用格子存放方块 ID，例如 `&"T"`、`&"L"`

这样做的好处：

- 新手容易理解
- 行列访问直观
- 后续做碰撞、锁定、消行时不需要推翻重写

## 方块数据表示

方块分成两层：

### 1. TetrominoData

这是“静态定义”，描述 7 种标准方块本身是什么。

每个方块定义统一包含：

- `id`：方块 ID
- `color`：显示颜色
- `spawn_box_size`：生成框宽度，当前统一采用 `4`
- `rotations`：4 个旋转状态，每个状态都是 4 个局部格子坐标

### 2. PieceState

这是“当前实例状态”，描述当前活动方块现在处于什么状态。

核心字段：

- `piece_id`：当前是哪一种方块
- `rotation_index`：当前旋转状态，范围 `0..3`
- `origin`：当前方块局部坐标系在棋盘上的原点

## 坐标约定

### 1. 棋盘坐标

- 使用 `Vector2i(x, y)`
- 左上角是 `(0, 0)`
- `x` 向右增加
- `y` 向下增加

示例：

- 最左上角格子：`Vector2i(0, 0)`
- 最右下角格子：`Vector2i(9, 19)`

### 2. 方块局部坐标

- 每个方块都定义在一个 `4 x 4` 的局部坐标框里
- 旋转状态中的每个格子都是相对局部原点的偏移
- 局部原点本身不直接代表方块中心，只代表这组偏移的参考点

### 3. 方块在棋盘上的实际格子

实际格子坐标的计算方式：

```text
board_cell = piece.origin + local_cell
```

这样后续无论做移动还是旋转，都只需要改：

- `origin`
- `rotation_index`

## 生成位置约定

第一阶段采用一个简单、稳定、适合新手理解的生成约定：

- 所有方块都使用 `4` 列宽的生成框
- 生成框在 `10` 列棋盘中居中
- 生成框左上角坐标固定为 `Vector2i(3, 0)`

也就是说：

- `spawn_origin = Vector2i(3, 0)`
- 当前阶段不处理出生在可视区域上方的隐藏行
- 当前阶段不处理更复杂的分 piece 生成修正

## 7 种标准方块定义格式

统一格式示例：

```gdscript
&"T": {
    "id": &"T",
    "color": Color("9b5de5"),
    "spawn_box_size": 4,
    "rotations": [
        [Vector2i(1, 0), Vector2i(0, 1), Vector2i(1, 1), Vector2i(2, 1)],
        ...
    ],
}
```

当前项目已为以下 7 种方块落地定义：

- `I`
- `O`
- `T`
- `S`
- `Z`
- `J`
- `L`

## 当前阶段允许做的最小验证

- 创建一个空棋盘状态
- 读取棋盘尺寸和生成点
- 从方块定义表中读取任意一个方块
- 创建一个 `PieceState`
- 把该方块的局部坐标转换成棋盘坐标用于显示

## 当前阶段不要做

- 真实生成流程
- 玩家输入
- 移动与旋转判定
- 自动下落与锁定
- 消行
- 分数与等级
- Rogue 扩展

## 这套结构对应到当前项目

- `Board` 节点持有 `BoardState`
- `ActivePiece` 节点持有 `PieceState`
- `GameManager` 只负责做最小初始化和展示联动
- `TetrominoData` 提供统一的 7 种方块静态定义
