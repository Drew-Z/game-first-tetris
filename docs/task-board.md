## 当前多端最小适配约定

### 布局断点

- 主菜单：
  - `>= 480px`：舒适区
  - `360px - 479px`：可用区，依赖滚动和换行
  - `< 360px`：暂不保证
- 游戏界面：
  - `>= 920px`：棋盘 + HUD 左右布局
  - `< 920px`：棋盘 + HUD 上下堆叠
- HUD / Help：
  - `< 920px`：进入紧凑表达
  - 长说明进入 Help，不回主 HUD

## 固定尺寸截图回归约定

### 目标尺寸

- Web 小窗口：`360 x 640`
- 安卓竖屏：`393 x 852`
- 安卓竖屏：`412 x 915`
- Windows：`960 x 640`
- Windows：`1024 x 768`
- Windows：`1280 x 720`

### 每个尺寸都检查 4 个画面

- 主菜单
- 游戏中经典模式
- 游戏中 Rogue 模式
- Help 面板

### 每个画面的判断标准

- 没有乱码
- 没有明显截断
- 没有明显重叠
- 没有关键按钮不可访问
- 当前布局方向符合该尺寸下的断点约定

### 当前最值得优先观察

- Web 小窗口 `360 x 640`
  - 菜单是否还能通过滚动完整访问
  - Rogue 开局选择是否会把按钮挤到不可点击
- 安卓竖屏 `393 x 852` / `412 x 915`
  - 游戏内上下堆叠是否自然
  - HUD 文本是否仍清楚
  - Help 是否还能完整阅读
- Windows `960 x 640`
  - 是否仍稳定保持左右布局
  - 侧栏是否开始过于拥挤
- Windows `1024 x 768` / `1280 x 720`
  - 是否处于当前最稳定的桌面阅读区间
