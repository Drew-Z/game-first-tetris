## 当前多端最小适配结论

- 主菜单：
  - `>= 480px` 较舒适
  - `360px - 479px` 仍可用，依赖滚动和换行
  - `< 360px` 暂不保证
- 游戏界面：
  - `>= 920px` 左右布局
  - `< 920px` 上下堆叠
- HUD / Help：
  - `< 920px` 进入紧凑表达
  - 长说明进入 Help，不回到主 HUD
