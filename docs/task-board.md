## 小尺寸字号 / 间距当前约定

- 重点尺寸：
  - `360 x 640`
  - `393 x 852`
- 当前收敛方式：
  - `360 x 640`：进入“超窄字号 / 间距态”
    - 标题字号再收一档
    - 正文字号保持可读，不再继续压文案
    - 区块间距和按钮区分隔略放宽，避免首屏过挤
    - Help / Pause / Main Menu / Restart / Rogue 选择按钮统一保持更明确的最小点击高度
  - `393 x 852`：进入“小尺寸字号 / 间距态”
    - 标题层级比默认态略收紧，但保留明显层级
    - 正文字号比超窄态更舒展一档
    - 区块间距与按钮区留白略大于超窄态，优先保证扫读顺畅
- 本轮固定尺寸复验结论：
  - `360 x 640`：经典模式、Rogue 模式、Help 继续保持可用，且比上一轮更稳
  - `393 x 852`：经典模式、Rogue 模式、Help 继续保持可用，当前无需继续为字号 / 间距单独改代码

## 窄宽度下 Rogue 信息区当前约定

- `Rogue` 区保持两层：
  - 摘要层：已选强化 / 本局带入 / 下局带入 / 下一轮提示
  - 效果层：当前生效数值与出生保护剩余次数
- 紧凑态文案优先使用短标签：
  - `已选：`
  - `本局带入：`
  - `下局带入：`
  - `下一选：`
- 效果说明在紧凑态下改成短句：
  - `硬降：+N`
  - `消行：+N/行`
  - `保护：N`
