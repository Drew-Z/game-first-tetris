## 当前触屏输入准备状态

- 已完成第一步：输入结构拆分
- 已完成第二步：最小触屏输入桥接层
- 已完成第三步：极简触屏控件占位层
- 已完成第六步：第一版正式触屏控件原型
- 当前输入层已明确区分：
  - 瞬时动作：旋转、Hard Drop、Hold、暂停 / 返回
  - 持续状态：左移、右移、软降
- 当前已经为后续触屏输入预留两个清晰接入口：
  - `trigger_game_action(...)`
  - `set_game_action_pressed(...)`
- 当前场景里已固定提供：
  - `TouchInputBridge.tap_action(...)`
  - `TouchInputBridge.set_touch_action_pressed(...)`
  - `TouchInputBridge.release_all_touch_actions()`
- 当前紧凑布局里已固定提供：
  - `TouchControls` 第一版正式触屏控件原型
  - 左移 / 右移 / 软降按钮走持续状态
  - 旋转 / Hard Drop / Hold / 暂停按钮走瞬时动作
- 当前第一版触屏控件原型已收敛为：
  - 移动按钮和动作按钮分组显示
  - 左移 / 软降 / 右移使用更明确的主按钮样式
  - 旋转 / 硬降 / 暂存 / 暂停使用较轻的次级按钮样式
  - 紧凑态下已具备更接近正式可玩的视觉与点击反馈层级
- 当前触屏占位控件行为已收紧为：
  - 只在紧凑布局里显示
  - Help、暂停、Rogue 选择、游戏结束时必须隐藏
  - 进入这些状态时会主动释放触屏持续输入
- 当前键盘输入和触屏来源已能并存，持续状态会按输入来源分别汇总，不会互相覆盖
- 当前第一版正式触屏控件原型的交互复验结论：
  - `393 x 852`：可用
  - `360 x 640`：勉强可用
  - 本轮更贴近真实使用的复验后，当前最明显问题已经收敛为：
    - `393 x 852`：主按钮按住已基本可用，但次级按钮排布仍偏紧
    - `360 x 640`：次级动作区和底部阅读区仍容易互相挤压
- 当前 `360 x 640` 的定点修复已补上：
  - 主按钮高度单独保留一档，不继续跟着次级按钮一起压缩
  - 次级动作按钮高度、字号、间距、面板底部留白继续缩一档
  - 优先把触屏控件总高度压低，减少和底部阅读区的直接冲突
- 当前 `360 x 640` 的次级动作区再小收一次：
  - 次级按钮高度从 `34` 收到 `32`
  - 次级字号再收一档
  - 次级按钮内容边距和圆角继续缩一档
  - 触屏控件整体底部留白继续减少，进一步给阅读区让空间
- 当前 `360 x 640` 的次级动作区微调方式：
  - 旋转 / 硬降继续保留为主要次级动作，维持展开宽度
  - 暂存 / 暂停收成更小的工具按钮，不再和前两项平均分配横向空间
  - 超窄态底部外边距再缩一档，进一步减少与阅读区的空间竞争
- 当前 `360 x 640` 的再次交互复验结论：
  - 当前仍保持“勉强可用”，还没有稳定推进到“可用”
  - 主按钮按住和状态切换恢复已基本稳定
  - 当前最明显遗留问题仍是次级动作区偏紧，在超窄尺寸下误触风险仍高于理想状态

## 小尺寸字号 / 间距当前约定

- 重点尺寸：
  - `360 x 640`
  - `393 x 852`
- 当前收敛方式：
  - `360 x 640`：进入“超窄字号 / 间距态”
    - 标题字号再收一档
    - 正文字号保持可读，不再继续压文案
    - 区块间距和按钮区分隔略放宽，避免首屏过挤
    - Help / Pause / Main Menu / Restart / Rogue 选择按钮统一保持更明确的最小点击高度
  - `393 x 852`：进入“小尺寸字号 / 间距态”
    - 标题层级比默认态略收紧，但保留明显层级
    - 正文字号比超窄态更舒展一档
    - 区块间距与按钮区留白略大于超窄态，优先保证扫读顺畅
- 本轮固定尺寸复验结论：
  - `360 x 640`：经典模式、Rogue 模式、Help 继续保持可用，且比上一轮更稳
  - `393 x 852`：经典模式、Rogue 模式、Help 继续保持可用，当前无需继续为字号 / 间距单独改代码

## 窄宽度下 Rogue 信息区当前约定

- `Rogue` 区保持两层：
  - 摘要层：已选强化 / 本局带入 / 下局带入 / 下一轮提示
  - 效果层：当前生效数值与出生保护剩余次数
- 紧凑态文案优先使用短标签：
  - `已选：`
  - `本局带入：`
  - `下局带入：`
  - `下一选：`
- 效果说明在紧凑态下改成短句：
  - `硬降：+N`
  - `消行：+N/行`
  - `保护：N`
