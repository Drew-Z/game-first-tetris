  - Rogue 原型迭代

- 经典模式完整可玩闭环

- 三种最小强化效果
- 最小局间带入壳层
- 暂停 / 中途重开 / 返回主菜单

- 多端最小适配第一轮断点收敛
- 固定尺寸截图回归约定
- 固定尺寸截图回归实际执行

## 多端最小适配当前约定

- 主菜单：
  - `>= 480px`：舒适区
  - `360px - 479px`：可用区，依赖滚动
  - `< 360px`：暂不保证
- 游戏界面：
  - `>= 920px`：棋盘 + HUD 左右布局
  - `< 920px`：棋盘 + HUD 上下堆叠
- HUD / Help：
  - `< 920px`：进入紧凑表达
  - 长说明统一进入 Help，不回主 HUD

## 固定尺寸截图回归结论

### 主菜单
- `360 x 640`：可用；按钮可访问，说明文字可读，主要依赖滚动兜底。
- `393 x 852`：可用；可直接阅读和进入模式。
- `412 x 915`：可用；可直接阅读和进入模式。
- `960 x 640`：可用；桌面窄窗下仍成立。
- `1024 x 768`：可用；处于稳定区间。
- `1280 x 720`：可用；处于稳定区间。

### 游戏中经典模式
- `360 x 640`：勉强可用；棋盘可见，但 HUD 主要依赖横向与纵向滚动，信息不适合高频读取。
- `393 x 852`：勉强可用；上下堆叠成立，但 HUD 需要滚动查看完整内容。
- `412 x 915`：勉强可用；比 `393 x 852` 稍好，但仍偏长。
- `960 x 640`：可用；左右布局清楚，信息读取正常。
- `1024 x 768`：可用；当前最稳定区间之一。
- `1280 x 720`：可用；当前最稳定区间之一。

### 游戏中 Rogue 模式
- `360 x 640`：勉强可用；主循环可见，但 Rogue 信息区阅读负担明显偏高。
- `393 x 852`：勉强可用；结构成立，但 Rogue 文本较长，需要滚动。
- `412 x 915`：勉强可用；可读性略好于 `393 x 852`，但仍未到舒适区。
- `960 x 640`：可用；左右布局成立，Rogue 信息可读。
- `1024 x 768`：可用；当前稳定。
- `1280 x 720`：可用；当前稳定。

### Help 面板
- `360 x 640`：可用；首屏已能看到帮助正文和关闭入口，但整体仍偏紧。
- `393 x 852`：可用；首屏可直接读到帮助摘要与关闭方式。
- `412 x 915`：可用；首屏可直接理解帮助要点，关闭入口清楚。
- `960 x 640`：可用；帮助正文与关闭入口已能在首屏稳定看到。
- `1024 x 768`：可用；首屏可见标题、有效正文和关闭方式。
- `1280 x 720`：可用；首屏可直接理解主要帮助信息。

## 当前最值得优先处理的后续点

- 窄宽度下 Rogue 信息的进一步压缩与分层
- 更系统的固定尺寸截图回归基线
- 更真实的设备级手工回归
