# 项目路线图

## 阶段 0：项目初始化

- 建立 Git 仓库与远程绑定
- 建立 Godot 项目骨架
- 建立基础文档、任务板和开发约定

## 阶段 1：标准俄罗斯方块最小闭环

- 搭建棋盘与方块数据结构
- 实现方块生成、移动、旋转、下落、锁定
- 实现消行、失败判定、重新开始
- 建立基础输入与刷新节奏

## 阶段 2：稳定性与手感

- 补充碰撞边界测试思路
- 调整重力、软降、硬降、延迟锁定等行为
- 优化场景结构、参数配置和可读性

## 阶段 3：表现层完善

- 补充 HUD、分数、等级、下一个方块预览
- 优化视觉反馈和音效接口
- 为后续扩展预留清晰边界

## 暂不进入的内容

- Rogue 系统
- 道具系统
- 局外成长
- 复杂关卡机制

这些方向会保留在未来规划中，但不会在“标准俄罗斯方块基础阶段”提前展开。
