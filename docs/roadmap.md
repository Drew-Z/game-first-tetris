## 当前项目状态

当前项目已经是一个：

- 可试玩的经典模式基线
- 可评估方向的 Rogue 原型
- 正在向 Web / 安卓 / Windows 共用结构收敛的原型界面

## 多端最小适配当前结论

### 断点约定
- 主菜单：
  - `>= 480px`：舒适区
  - `360px - 479px`：可用区
  - `< 360px`：暂不保证
- 游戏界面：
  - `>= 920px`：左右布局
  - `< 920px`：上下堆叠
- HUD / Help：
  - `< 920px`：紧凑表达
  - 详细说明进入 Help

### 固定尺寸截图回归结论
- 主菜单：6 个目标尺寸下均可用。
- 经典模式：`960 x 640` 及以上可用；更窄尺寸为勉强可用。
- Rogue 模式：`960 x 640` 及以上可用；更窄尺寸为勉强可用。
- Help 面板：`360 x 640`、`393 x 852`、`412 x 915`、`960 x 640` 已完成首屏可见性修复；`1024 x 768`、`1280 x 720` 仍值得继续收敛。

## 当前最值得继续收敛的方向

- 优先：Help 面板在桌面中等尺寸下的进一步首屏收敛
- 其次：窄宽度下 Rogue 信息进一步压缩
- 之后：固定尺寸截图回归基线固化
