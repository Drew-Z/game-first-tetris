# 项目路线图

## 已完成阶段
1. 第一阶段：最小可玩标准俄罗斯方块
2. 第二阶段：现代标准增强主线
3. 第三阶段：第一轮表现层增强
4. 第四阶段：Rogue 原型三轮实验链路
5. 原型冻结后的试玩修复与多端最小适配起步

## 当前项目状态

当前项目已经是一个：

- 可试玩的经典模式基线
- 已保留节点的 Rogue 原型
- 已保留节点的跨平台布局打磨结果
- 正在 `feature/device-size-manual-review` 上继续做真实设备尺寸 / 真实窗口体验回归

## 多端最小适配当前结论

### 断点约定
- 主菜单：
  - `>= 480px`：舒适区
  - `360px - 479px`：可用区
  - `< 360px`：暂不保证
- 游戏界面：
  - `>= 920px`：左右布局
  - `< 920px`：上下堆叠
- HUD / Help：
  - `< 920px`：紧凑表达
  - 详细说明进入 Help

### 固定尺寸截图回归结论
- 主菜单：6 个目标尺寸下均可用。
- 经典模式：`360 x 640`、`393 x 852`、`412 x 915`、`960 x 640` 及以上可用。
- Rogue 模式：`360 x 640`、`393 x 852`、`412 x 915`、`960 x 640` 及以上可用。
- Help 面板：`360 x 640`、`393 x 852`、`412 x 915`、`960 x 640`、`1024 x 768`、`1280 x 720` 当前都已达到首屏可见标题、正文和关闭方式的最低可用线。

## 当前最值得继续收敛的方向

- 优先：固定尺寸截图回归基线固化
- 其次：更真实的设备级手工回归
- 之后：更细的字号 / 间距断点策略

## 当前分支阶段结论

- `feature/cross-platform-layout-polish` 已经作为“跨平台布局打磨节点”保留。
- 当前工作分支已经切换到 `feature/device-size-manual-review`。
- 当前分支只负责：
  - 真实设备尺寸人工回归
  - 真实窗口体验确认
  - 验证现有跨平台布局收敛在真实使用场景里是否成立

### 窄宽度 Rogue 信息表达约定
- 摘要与效果分开显示，不再把强化结果和轮次提示混成一大段
- 下一轮提示统一收敛为短句，例如 `下一选：第 2 轮 / 2 行后`
- 生效结果统一收敛为短句，例如 `硬降：+1`、`消行：+1/行`、`保护：1`

### 安卓竖屏紧凑态约定
- 目标优先尺寸：`393 x 852`、`412 x 915`
- 进入条件：`< 920px` 的上下堆叠布局下，同时满足 `<= 430px` 宽度和 `>= 800px` 高度
- 当前收敛策略：
  - 棋盘缩一档显示
  - Playfield 上下留白缩小
  - Next / Hold 缩一档
  - Help 使用更短的竖屏帮助文案
  - `393 x 852` 再进入更窄一档棋盘尺寸，优先保证 HUD 首屏可读性

### 超窄紧凑态约定
- 目标优先尺寸：`360 x 640`
- 进入条件：宽度 `<= 360px`，并处于 `< 920px` 的上下堆叠布局
- 当前收敛策略：
  - 棋盘再缩一档
  - Playfield 最小高度再下调
  - HUD 进入更小的字号 / 间距策略，标题层级略收紧
  - 预览尺寸和帮助文案长度继续保持紧凑
  - 主菜单短文案 + 更明确的按钮点击区
  - Help / 会话按钮最小点击高度提升
- 当前结论：
  - 主菜单、经典模式、Rogue 模式、Help 都已达到最低可用线

### 小尺寸字号 / 间距策略
- 目标优先尺寸：`360 x 640`、`393 x 852`
- 当前约定：
  - `360 x 640`：用更紧的标题字号和更稳的按钮点击区，优先保证“可读、可点、可操作”
  - `393 x 852`：保持比超窄态更舒展一档的正文与区块间距，避免竖屏首屏读起来过挤
- 当前状态：
  - 两档都已进入第一轮字号 / 间距收敛
  - 固定尺寸复验后，两档都继续保持“可用”，且没有发现必须立即继续修改的显示问题
  - 后续如继续细化，更适合围绕字号和点击区做小步打磨，而不是再压主布局结构

## 当前分支职责说明

- `feature/rogue-prototype`：已保留 Rogue 原型节点，作为后续 Rogue 深化的基线
- `feature/cross-platform-layout-polish`：已保留为跨平台布局打磨节点
- `feature/device-size-manual-review`：当前只继续推进真实设备尺寸 / 真实窗口体验回归，不继续扩 Rogue 功能
