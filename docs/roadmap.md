# 项目路线图

## 阶段 0：项目初始化

- 建立 Git 仓库与远程绑定
- 建立 Godot 项目骨架
- 建立基础文档、任务板和开发约定

## 阶段 1：标准俄罗斯方块最小闭环

- 先按 [`docs/stage-1-rules.md`](stage-1-rules.md) 明确规则边界
- 按小步任务拆分实现棋盘、方块、移动、下落、锁定
- 完成消行、失败判定、重新开始的最小闭环
- 只做“最小可玩的标准俄罗斯方块”，不提前扩展高级规则

## 阶段 2：现代标准增强与扩展准备

- 先补 Hard Drop、Next Queue、Hold、等级等更接近现代标准俄罗斯方块的能力
- 再做少量结构整理，例如方块来源接口、规则参数入口、运行结果数据出口
- 本阶段仍然不引入 Rogue 玩法本身，只为未来扩展保留清晰边界

当前状态：
- 现代标准增强主线已完成
- 后续若继续推进，优先进入“扩展准备”这条结构整理支线

## 阶段 3：表现层完善

- 补充 HUD、分数、等级、下一个方块预览
- 优化视觉反馈和音效接口
- 为后续扩展预留清晰边界

## 暂不进入的内容

- Rogue 系统
- 道具系统
- 局外成长
- 复杂关卡机制

这些方向会保留在未来规划中，但不会在“标准俄罗斯方块基础阶段”提前展开。
