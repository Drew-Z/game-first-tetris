- 可试玩的经典模式基线

- 正在向 Web / 安卓 / Windows 共用结构收敛的原型界面

## 当前多端适配最小结论

### 布局断点

- 主菜单：
  - `>= 480px`：舒适区
  - `360px - 479px`：可用区
  - `< 360px`：暂不保证
- 游戏界面：
  - `>= 920px`：左右布局
  - `< 920px`：上下堆叠
- HUD / Help：
  - `< 920px`：紧凑表达
  - 详细说明统一进入 Help
