# 项目路线图

## 已完成阶段
1. 第一阶段：最小可玩标准俄罗斯方块
2. 第二阶段：现代标准增强主线
3. 第三阶段：第一轮表现层增强
4. 第四阶段：Rogue 原型三轮实验链路
5. 原型冻结后的试玩修复与多端最小适配起步

## 当前项目状态

当前项目已经是一个：

- 可试玩的经典模式基线
- 可评估方向的 Rogue 原型
- 正在向 Web / 安卓 / Windows 共用结构收敛的原型界面

## 多端最小适配当前结论

### 断点约定
- 主菜单：
  - `>= 480px`：舒适区
  - `360px - 479px`：可用区
  - `< 360px`：暂不保证
- 游戏界面：
  - `>= 920px`：左右布局
  - `< 920px`：上下堆叠
- HUD / Help：
  - `< 920px`：紧凑表达
  - 详细说明进入 Help

### 固定尺寸截图回归结论
- 主菜单：6 个目标尺寸下均可用。
- 经典模式：`960 x 640` 及以上可用；更窄尺寸为勉强可用。
- Rogue 模式：`960 x 640` 及以上可用；更窄尺寸为勉强可用。
- Help 面板：当前是最明显的薄弱项；窄尺寸不可用，桌面尺寸仅勉强可用。

## 当前最值得继续收敛的方向

- 优先：Help 面板的首屏可见性与小窗口表达
- 其次：窄宽度下 Rogue 信息进一步压缩
- 之后：固定尺寸截图回归基线固化
