# 测试清单

## 基础运行

- 项目可正常打开
- 经典模式可进入并正常游玩
- Rogue 模式可进入并正常游玩
- Godot 无头运行不报 Unicode 解析错误

## 经典模式

- 方块生成、移动、旋转、软降、Hard Drop 正常
- Hold 正常
- 锁定、消行、计分、等级正常
- 暂停 / 重开 / 返回主菜单正常

## Rogue 模式

- 开局前第一次 `3 选 1` 正常
- 局内第二次选择在累计消除 `2` 行后触发
- 局内第三次选择在累计消除 `4` 行后触发
- Hard Drop 奖励、消行奖励、一次出生保护正常
- 局间带入只在 Rogue 的 Restart 闭环中生效
- Rogue HUD 可正确显示已选强化、叠加次数、剩余保护次数

## HUD / Help

- 正常游戏中，HUD 按钮不会误吃掉方向键、Space、C
- Help 打开时会暂停主循环，并阻断方块控制输入
- Help 关闭后会恢复到打开前的暂停状态
- 长说明只在 Help 中出现，不回到主 HUD

## 多端最小适配

### 主菜单
- `>= 480px` 宽度时，主菜单阅读舒适
- `360px - 479px` 宽度时，主菜单仍可通过滚动完整访问
- `< 360px` 目前不作为保证区间

### 游戏界面
- `>= 920px` 时，棋盘与 HUD 保持左右布局
- `< 920px` 时，棋盘与 HUD 改为上下堆叠

### HUD / Help
- `< 920px` 时，Next / Hold 与系统按钮进入紧凑表达
- 较小窗口下，HUD 文本仍可读
- Help 面板在较小窗口下仍完整可访问
