# 测试清单

## 基础运行
- 项目可正常打开
- 经典模式可进入并正常游玩
- Rogue 模式可进入并正常游玩
- Godot 无头运行不报 Unicode 解析错误

## 经典模式
- 方块生成、移动、旋转、软降、Hard Drop 正常
- Hold 正常
- 锁定、消行、计分、等级正常
- 暂停 / 重开 / 返回主菜单正常

## Rogue 模式
- 开局前第一次 `3 选 1` 正常
- 局内第二次选择在累计消除 `2` 行后触发
- 局内第三次选择在累计消除 `4` 行后触发
- Hard Drop 奖励、消行奖励、一次出生保护正常
- 局间带入只在 Rogue 的 Restart 闭环中生效
- Rogue HUD 可正确显示已选强化、叠加次数、剩余保护次数

## HUD / Help
- 正常游戏中，HUD 按钮不会误吃方向键、`Space`、`C`
- Help 打开时会暂停主循环并阻断方块控制输入
- Help 关闭后会恢复到打开前的暂停状态
- 长说明只在 Help 中出现，不回到主 HUD

## 固定尺寸截图回归

### 目标尺寸
- Web 小窗口：`360 x 640`
- 安卓竖屏：`393 x 852`
- 安卓竖屏：`412 x 915`
- Windows：`960 x 640`
- Windows：`1024 x 768`
- Windows：`1280 x 720`

### 每个尺寸固定检查 4 个画面
- 主菜单
- 游戏中经典模式
- 游戏中 Rogue 模式
- Help 面板

### 当前回归结论
- 主菜单：6 个尺寸下均可用
- 经典模式：`960 x 640`、`1024 x 768`、`1280 x 720` 可用；其余为勉强可用
- Rogue 模式：`960 x 640`、`1024 x 768`、`1280 x 720` 可用；其余为勉强可用
- Help 面板：`360 x 640`、`393 x 852`、`412 x 915`、`960 x 640` 可用；`1024 x 768`、`1280 x 720` 仍按勉强可用跟踪

### Help 首屏可见性额外判断
- 打开后首屏就能看到帮助标题
- 打开后首屏就能看到有效正文，而不是只看到棋盘或系统区
- 打开后首屏就能看到明确关闭方式（`Close Help` 或 `Esc`）
- 主要帮助信息不需要先大量滚动才能理解

### 判断标准
- 没有乱码
- 没有明显截断
- 没有明显重叠
- 没有关键按钮不可访问
- 当前布局方向符合断点约定
