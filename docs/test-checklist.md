# 测试清单

## 阶段 1 当前可验证能力

### 1. 项目可正常打开

- 使用 Godot 打开项目不会报场景或脚本错误
- 进入主场景后可以看到棋盘、活动方块和右侧信息面板

### 2. 开局生成活动方块

- 进入游戏后会生成一个活动方块
- 当前默认生成 `T` 方块
- 方块出生位置应与右侧面板显示的坐标一致

### 3. 左右移动与左右边界

- 按左方向键，活动方块向左移动一格
- 按右方向键，活动方块向右移动一格
- 活动方块不能移出棋盘左右边界

### 4. 自动下落与到底停止

- 不操作时，活动方块会按固定间隔自动向下移动
- 活动方块触底后会停止继续下落并锁定到棋盘
- 锁定后，棋盘上会保留该方块的静态格子显示
- 锁定后，会立即生成一个新的活动方块
- 新活动方块仍从当前约定的出生位置出现
- 流程可以持续形成“生成 -> 下落 -> 锁定 -> 再生成”循环

### 5. 与静态格子的基础碰撞

- 当棋盘上已有静态格子时，活动方块左右移动不能进入这些格子
- 当活动方块下方已有静态格子时，活动方块会停止继续下落并锁定
- 静态格子会持续保留在棋盘上，后续活动方块需要绕开它们

### 6. 出生位置校验与游戏结束

- 当新活动方块需要生成时，会先检查出生位置是否可用
- 如果出生位置已被静态格子占用，则进入游戏结束状态
- 游戏结束后，不会继续生成新方块
- 游戏结束后，当前不会再响应左右输入
- 游戏结束后，当前不会再继续自动下落
