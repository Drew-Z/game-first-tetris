# 测试清单

## 阶段 1 当前可验证能力

### 1. 项目可正常打开

- 使用 Godot 打开项目不会报场景或脚本错误
- 进入主场景后可以看到棋盘、活动方块和右侧信息面板

### 2. 开局生成活动方块

- 进入游戏后会生成一个活动方块
- 当前默认生成 `T` 方块
- 方块出生位置应与右侧面板显示的坐标一致

### 3. 左右移动与左右边界

- 按左方向键，活动方块向左移动一格
- 按右方向键，活动方块向右移动一格
- 活动方块不能移出棋盘左右边界

### 4. 自动下落与到底停止

- 不操作时，活动方块会按固定间隔自动向下移动
- 活动方块触底后会停止继续下落并锁定到棋盘
- 锁定后，棋盘上会保留该方块的静态格子显示
- 锁定后，不会自动生成新方块
- 锁定后，不再存在可移动活动方块

## 当前明确未验证的内容

- 静态方块碰撞
- 旋转
- 消行
- 计分
