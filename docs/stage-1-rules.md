# 阶段 1：标准俄罗斯方块规则清单与最小实现拆分

## 文档目标

这份文档只服务于“第一阶段最小可玩的标准俄罗斯方块”。

- 先把规则边界说清楚
- 先把实现顺序拆小
- 先保证每一步都能单独验证

本阶段不讨论 Rogue 扩展，也不提前设计后续复杂系统。

## 第一阶段规则清单

### 1. 棋盘范围

- 使用固定大小的矩形棋盘
- 标准可玩范围先采用 `10 列 x 20 行`
- 逻辑判断必须以网格坐标为准，不依赖视觉位置硬算

### 2. 方块集合

- 只使用标准 7 种四格方块：`I O T S Z J L`
- 每个方块由固定的格子布局表示
- 本阶段只要求“能正确出现和落下”，不要求高级随机规则

### 3. 出生规则

- 每次场上只能有一个当前活动方块
- 当前方块锁定后，才生成下一个方块
- 新方块生成时，若出生位置已被占用，则判定游戏结束

### 4. 移动规则

- 活动方块可以左移、右移
- 只有目标位置合法时才允许移动
- 越界或与已锁定方块重叠时，移动无效

### 5. 下落规则

- 活动方块会按固定节奏自动下落
- 玩家可以触发软降，让方块更快下落
- 本阶段先不要求硬降

### 6. 旋转规则

- 活动方块可以旋转
- 旋转后若越界或重叠，则本次旋转无效
- 本阶段先不实现 wall kick、T-Spin 等高级规则
- `O` 方块保持其稳定形态即可

### 7. 锁定规则

- 当活动方块无法继续向下移动时，进入锁定
- 第一阶段可以采用最简单规则：不能下移时立即锁定
- 锁定后要把方块写入棋盘静态数据

### 8. 消行规则

- 某一整行被填满时，该行消除
- 被消除行上方的内容整体下移
- 第一阶段只要求消行逻辑正确，不要求动画和音效

### 9. 结束与重开

- 新方块无法正常出生时，游戏结束
- 游戏结束后可以重新开始
- 第一阶段不要求完整菜单，只要能重新开局即可

### 10. 表现层要求

- 玩家能看清棋盘边界、已锁定方块、当前活动方块
- 第一阶段允许使用简单方块色块或占位显示
- 不要求分数、等级、下一个方块预览、特效、音效

## 这一阶段必须做

- 固定棋盘尺寸与网格坐标系统
- 标准 7 种方块的数据表示
- 单个活动方块的生成、移动、旋转、自动下落、软降、锁定
- 锁定后的棋盘数据更新
- 满行检测与消行
- 游戏结束判定
- 重新开始入口
- 一个最小可运行场景，能完整跑通从开局到结束的闭环

## 当前不要做

- Rogue 元素或局外成长
- 道具、技能、特殊方块
- Hard Drop
- Hold
- Next Queue 预览
- 分数、等级、连击、奖励算法
- Wall Kick、SRS 细节、T-Spin 判定
- 动画、音效、粒子反馈
- 存档、设置、复杂 UI

## 第一阶段最小实现任务

### 任务 1：确定棋盘与场景骨架

目标：
定义主游戏场景、棋盘节点职责、基础显示区域。

完成标准：

- 项目里有独立的主玩法场景
- 棋盘范围明确为 `10 x 20`
- 能看到棋盘占位区域

验证方式：

- 启动项目后能进入该场景
- 棋盘区域尺寸和边界显示正确

### 任务 2：定义方块与棋盘数据结构

目标：
先把“数据怎么表示”定清楚，再开始行为实现。

完成标准：

- 棋盘可用二维网格或等价结构表达
- 7 种方块有统一的数据格式
- 活动方块状态至少包含：类型、旋转状态、位置

验证方式：

- 通过调试输出或临时显示确认数据生成正确
- 切换不同方块时数据结构保持一致

### 任务 3：实现方块生成与基础显示

目标：
让一个活动方块能够出生并显示在棋盘中。

完成标准：

- 开局生成一个合法方块
- 方块显示位置与逻辑坐标一致
- 出生越界或重叠会被识别

验证方式：

- 运行项目后能看到活动方块
- 多次重开能稳定生成不同方块

### 任务 4：实现左右移动与基础碰撞

目标：
先完成最容易验证的平面移动。

完成标准：

- 可以左移和右移
- 遇到边界或已锁定格子时不能移动

验证方式：

- 输入左右方向时位置变化正确
- 靠墙时不会穿出边界

### 任务 5：实现自动下落、软降与锁定

目标：
形成“方块从出生到落地”的最小闭环。

完成标准：

- 方块会按固定节奏自动下落
- 软降会加快下落
- 不能继续下移时立即锁定到棋盘

验证方式：

- 不操作时方块会持续下落
- 按住软降时速度明显更快
- 落地后会变成静态格子

### 任务 6：实现旋转与旋转合法性判断

目标：
补上核心操作，但暂不做高级旋转规则。

完成标准：

- 活动方块可旋转
- 非法旋转会被拒绝
- `O` 方块表现稳定

验证方式：

- 可旋转方块在空旷区域正常旋转
- 靠墙或碰撞时不会转进非法位置

### 任务 7：实现消行

目标：
让棋盘具备基础清除反馈。

完成标准：

- 满行会被清除
- 上方格子整体下移
- 可连续处理多行

验证方式：

- 人工构造满行后能正确消除
- 消除后棋盘状态与显示一致

### 任务 8：实现结束与重新开始

目标：
闭合第一阶段的完整玩法循环。

完成标准：

- 无法出生时判定游戏结束
- 可以从结束状态重新开始
- 重开后棋盘与活动方块状态重置

验证方式：

- 堆高到出生区后会结束
- 重开后从干净棋盘重新开始

## 建议提交粒度

为了适合新手学习，建议按任务拆成多个小提交，而不是一次写完。

- `feat(board): create playfield scene skeleton`
- `feat(data): define tetromino and board data model`
- `feat(spawn): add active piece spawning`
- `feat(move): add horizontal movement and collision checks`
- `feat(drop): add gravity soft drop and locking`
- `feat(rotate): add basic rotation validation`
- `feat(clear): add line clear logic`
- `feat(loop): add game over and restart flow`

这些提交名只是示例，本阶段先不执行代码实现。
